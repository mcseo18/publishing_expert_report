❓ 이렇게 사용하세요

  1. 새 교재 만들기: 주제와 키워드를 넣으면 1단계(목차 초안)가 자동으로 시작됩니다.
  2. 1단계 목차 확정: 목차를 읽고 고친 뒤 초록색 [목차 확정] 버튼을 누르면 2~6단계가 이어서 진행됩니다.
  3. 기다리기: 진행 중에는 상단 진도 바가 움직입니다. 끝나면 소리와 알림으로 알려 드립니다.
  4. 4단계 원고 확인: 품질 점검표에서 '틀 원고'·'약함' 단원을 확인하고, 원고를 열어 직접 고칠 수 있습니다.
  5. 5단계 그림 확인: 마음에 들지 않는 그림은 [이 그림만 다시 만들기]로 한 장씩 바꿀 수 있습니다.
  6. 6단계 출판물 받기: [전체 산출물 zip 받기] 또는 [출판 폴더 열기]로 PDF·Word·블로그 파일을 받습니다.
• 완료된 단계를 다시 실행하면 직전 결과가 자동 백업되며, ⚙️ 설정 탭의 [백업 · 되돌리기]에서 복원할 수 있습니다.
• 화면 위에 빨간 띠가 보이면 서버가 꺼진 것입니다. 폴더의 교재플랫폼_시작.bat을 다시 실행하세요.
